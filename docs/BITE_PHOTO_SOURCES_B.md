# Additional sting and tick reference photographs

Verified on 2026-09-13. These five files are real photographs, not generated
artwork. Individual file licenses were checked; the generic Wikimedia footer
license was not treated as a photograph license. No CC BY or CC BY-SA files were
selected. Public-domain government works are specifically public domain in the
United States; CC0 and author dedications have their stated legal scope.

Use these as educational examples, never as a way to confirm a diagnosis.
Reported reactions are labeled as reported. Swelling in a reference photograph
does not establish how severe a user's condition is. Tick-attachment photos are
not examples of Lyme disease or proof of any infection. Existing clinical safety
advice should remain visible. Use `BoxFit.contain` to retain the full image.

The importer (`tools/import_bite_photos_b.py`) applies only EXIF orientation,
RGB conversion, proportionate downscaling to at most 1400 pixels on the longest
edge, and JPEG compression. It does not crop, retouch skin, or generate pixels.
Original file metadata is removed from the app derivative; credits and license
evidence are preserved here. Commons thumbnails were used where the source
server requested thumbnail delivery instead of original downloads.
